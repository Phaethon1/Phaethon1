## Andy Paparountas, PhD, MBA

Founder, **Sovereign Governance Systems Ltd** (UK).

I work on one problem: **how a machine proves what it did to a party that has no reason to trust it.** Hardware-attested execution (AMD SEV-SNP, Intel TDX), tamper-evident audit trails, and differential-privacy budgets — aimed at health and genomic data that cannot legally leave its jurisdiction, where the usual answer of "send the data to the analysis" is not available.

The inversion: *send the tool to the data, and return proof of what ran.*

### Current work

- **ARIA Capsule** — sovereignty-preserving computation with hardware attestation and a tamper-evident receipt chain. Patent pending: US 19/693,491, GB2612045.1. Hardware attestation is validated on real silicon; there is no production deployment yet.
- **[AI Alliance Project Tapestry](https://github.com/The-AI-Alliance/tapestry)** — contributing to the data-governance discussion on verifiable data residency.
